# Timer Module (타이머 기능)

논리회로실험 팀 프로젝트 - 타이머 기능 담당 파트

담당: 2413540 박세은

## 요구사항

- 설정한 시간부터 1초마다 감소: `03:00 -> 02:59 -> ... -> 00:00`
- 초가 0일 때 분에서 빌림: `01:00 -> 00:59`
- `00:00` 도달 시 버저 요청
- `00:00`에서 정지, 되돌아가지 않음
- 설정 시 증가와 감소 모두 지원

## 파일

| 파일 | 설명 |
|---|---|
| `timer.v` | 타이머 본체. 팀 통합 시 이 파일만 가져가면 됨 |
| `timer_tb.v` | 타이머 단독 테스트벤치 |
| `timer_top.v` | 보드 단독 검증용 Top. 통합 시에는 사용하지 않음 |
| 그 외 | 기존 실습에서 가져온 공용 모듈. 팀 레포에 이미 있으면 중복 제거 |

## timer.v 인터페이스

### Output

| 신호 | 폭 | 설명 |
|---|---|---|
| `o_min` | 6 | 남은 분 |
| `o_sec` | 6 | 남은 초 |
| `o_run` | 1 | 카운트다운 중 |
| `o_expire` | 1 | `00:00` 도달, 버저 요청 레벨 |
| `o_expire_start` | 1 | `00:00` 도달 순간 1클럭 펄스. 악보 인덱스 리셋용 |

### Input

| 신호 | 설명 |
|---|---|
| `i_set_en` | 타이머 설정 모드일 때 1. 동작 중 1이 되면 자동 일시정지 |
| `i_set_min` | 분 변경 입력. 내부에서 상승 엣지 검출 |
| `i_set_sec` | 초 변경 입력. 내부에서 상승 엣지 검출 |
| `i_set_dec` | 1이면 설정 시 감소, 0이면 증가 |
| `i_tick` | 1Hz |
| `i_start` | 시작 / 일시정지 토글 |
| `i_clear` | 정지 및 `00:00` 초기화 |

### Parameter

| 이름 | 기본값 | 설명 |
|---|---|---|
| `EXPIRE_SEC` | 5 | `00:00` 도달 후 버저 유지 시간. 0이면 수동 해제까지 유지 |

## 통합 시 참고

- 스위치 신호와 리모컨 신호는 OR로 묶어서 넣으면 됨. 내부에서 상승 엣지를 잡음
- 스위치를 클럭으로 쓰지 않으므로 clock multiplexer 경고가 생기지 않음
- blink는 `ctrl`의 `c_mode`, `c_targ`로 판단. 타이머 쪽 추가 신호 불필요
- 버저는 직접 구동하지 않고 `o_expire`만 내보냄. arbiter에서 알람 조건과 OR

## 단독 검증 방법

### 시뮬레이션

```
iverilog -g2012 -o timer_tb.out timer_tb.v
vvp timer_tb.out
```

### 보드

`timer_top.v`를 Top-Level로 하여 컴파일 후 다운로드.
디스플레이는 `FF MM.SS` 형식.

| 스위치 | 기능 |
|---|---|
| sw[0] | 설정 모드 ON/OFF |
| sw[1] | 설정 대상 초 / 분 |
| sw[2] | 값 변경 |
| sw[3] | 누르고 있는 동안 감소 |
| sw[4] | 시작 / 일시정지 |
| sw[5] | 정지 및 초기화 |
