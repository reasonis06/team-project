# Timer Module (타이머 기능)

논리회로실험 팀 프로젝트 - 타이머 기능 담당 파트

담당: 2413540 박세은

## 요구사항

- 설정한 시간부터 1초마다 감소: `01:00:00 -> 00:59:59 -> ... -> 00:00:00`
- 초가 0이면 분에서, 분·초가 0이면 시에서 빌림
- `00:00:00` 도달 시 버저 요청
- `00:00:00`에서 정지, 되돌아가지 않음
- 설정 시 증가와 감소 모두 지원 (시 0~23, 분·초 0~59, 끝에서 반대쪽으로 넘어감)

## 파일

| 파일 | 설명 |
|---|---|
| `/timer.v` (레포 루트) | 타이머 본체. 통합 top(`top.v`)에서 `` `include "timer.v" ``로 사용 |
| `timer/timer_tb.v` | 타이머 단독 테스트벤치 |
| `timer/demo/timer_top.v` | 보드 단독 검증용 Top (분:초만 사용). 통합 시에는 사용하지 않음 |

## timer.v 인터페이스

### Output

| 신호 | 폭 | 설명 |
|---|---|---|
| `o_hour` | 5 | 남은 시 (0~23) |
| `o_min` | 6 | 남은 분 |
| `o_sec` | 6 | 남은 초 |
| `o_run` | 1 | 카운트다운 중 |
| `o_expire` | 1 | `00:00:00` 도달, 버저 요청 레벨 |
| `o_expire_start` | 1 | `00:00:00` 도달 순간 1클럭 펄스. 악보 인덱스 리셋용 |

### Input

| 신호 | 설명 |
|---|---|
| `i_set_en` | 타이머 모드일 때 1. 설정 입력은 정지 상태에서만 반영되고, 동작 중에는 무시됨 (일시정지는 `i_start`로) |
| `i_set_hour` | 시 변경 입력. 내부에서 상승 엣지 검출. 쓰지 않으면 `1'b0` 연결 |
| `i_set_min` | 분 변경 입력. 내부에서 상승 엣지 검출 |
| `i_set_sec` | 초 변경 입력. 내부에서 상승 엣지 검출 |
| `i_set_dec` | 1이면 설정 시 감소, 0이면 증가 |
| `i_tick` | 1Hz |
| `i_start` | 시작 / 일시정지 토글 |
| `i_clear` | 정지 및 `00:00:00` 초기화 |

### Parameter

| 이름 | 기본값 | 설명 |
|---|---|---|
| `EXPIRE_SEC` | 5 | `00:00:00` 도달 후 버저 유지 시간. 0이면 수동 해제까지 유지 |

## 통합 시 참고

- 스위치 신호와 리모컨 신호는 OR로 묶어서 넣으면 됨. 내부에서 상승 엣지를 잡음
- 스위치를 클럭으로 쓰지 않으므로 clock multiplexer 경고가 생기지 않음
- blink는 `ctrl`의 `c_mode`, `c_targ`로 판단. 타이머 쪽 추가 신호 불필요
- 버저는 직접 구동하지 않고 `o_expire`만 내보냄. Top에서 알람 조건과 OR
- 시 기능을 화면에 쓰려면 팀 코드에서 아래 3곳 수정 필요. 수정 전에도 기존 연결 그대로 컴파일·동작함 (시는 항상 0)
  - `ctrl.v` : 타이머 모드에서 자리 전환이 시까지 가도록, `o_timer_set_hour` 추가
  - `arbiter.v` : 타이머 모드에서 시 자리에 `i_timer_hour` 표시
  - `top.v` : `.o_hour(timer_hour)`, `.i_set_hour(timer_set_hour)` 연결

## 단독 검증 방법

### 시뮬레이션

`timer/` 폴더에서 실행

```
iverilog -g2012 -o timer_tb.out timer_tb.v
vvp timer_tb.out
```

- 설정(증가·감소·시 랩어라운드), `set_en=1` 유지 상태에서 시작, `01:01:01 -> 00:00:00`
  3661초 동안 매 초 정확히 1초씩 감소하는지 자동 검사, 버저 요청·해제, 초기화
- 마지막에 `RESULT : ALL PASS` 나오면 정상

### 보드

`timer_top.v`를 Top-Level로 하여 컴파일 후 다운로드.
디스플레이는 `FF MM.SS` 형식.

| 스위치 | 기능 |
|---|---|
| sw[0] | 설정 모드 ON/OFF |
| sw[1] | 설정 대상 초 / 분 |
| sw[2] | 값 변경 |
| sw[3] | 누르고 있는 동안 감소 |
| sw[4] | 시작 / 일시정지 |
| sw[5] | 정지 및 초기화 |
